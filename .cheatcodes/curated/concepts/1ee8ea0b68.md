# Symptom

The reasoning workflow's frame position instructed the agent to identify target code while granting only read, leading it to guess README, package, and source paths that did not exist.

# Cause

The runtime hid the effective tool grant, and the frame procedure required discovery without granting bash or another listing/search capability.

# Fix

Grant bash where discovery is required, explicitly describe the grant in the prompt, instruct agents to use ls, find, or rg rather than guess paths, and record unresolved targets in unknowns.

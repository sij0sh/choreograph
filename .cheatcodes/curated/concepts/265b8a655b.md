# Purpose

Ensure workflow procedures, tool grants, runtime prompts, operators, invariants, and specifications describe the same executable behavior.

# Steps

1. Compare each position's instructions with its granted tools and narrow grants where the position is read-only.
2. Ensure discovery steps have ls, find, rg, or equivalent capabilities and explicitly prohibit path guessing.
3. Check operators for required capabilities and qualify workflow-wide invariants when restrictions vary by position.
4. Check the specification for stale paths, schema claims, routing keys, tool grants, and enforcement statements.
5. Add prompt-rendering coverage for narrowed, wide, empty, and omitted tool grants.

# Validation

Run the project test suite, parse the affected workflow, discover all workflows for diagnostics, and render a real prompt to confirm that its Tools section matches the active grant.

# Symptom

A script-position process exit remains unable to satisfy the delivered gate.

# Cause

delivered=true is set only after prompt delivery in coordinator.ts:191 for the stay case, while a script position never delivers a prompt.

# Fix

Handle process-exit completion with its own gate treatment instead of the model-delivery gate.

# Symptom

Validation fails with `checkpoint: must not have additional properties` when workflow_transition receives a checkpoint object containing unsupported fields.

# Cause

The submitted arguments include properties that are not accepted by the workflow_transition checkpoint schema.

# Fix

Conform checkpoint arguments to the workflow_transition schema and remove any properties reported as additional before retrying.

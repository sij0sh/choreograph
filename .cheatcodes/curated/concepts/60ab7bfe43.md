# Symptom

At oversized iterations, the loop aggregate reference points to a 192-B ref-JSON and the consumer never receives the payload.

# Cause

Downstream resolution does not transparently materialize the payload represented by the aggregate reference.

# Fix

Resolve and materialize aggregate references before delivering loop outputs to consumers, and cover oversized iterations with an end-to-end regression test.

# Symptom

Promoted WORKFLOW.md can contain only frontmatter and lose the overview or title; persistence and restore can silently swallow errors; and workflowsRoot wiring currently exists only in src/index.ts.

# Cause

These limitations are present in the current generated-definition pin, persistence, restore, and configuration wiring paths.

# Fix

When implementing the Pi-facing tools, preserve the promoted overview and title, surface persistence and restore errors, and make workflowsRoot available through the relevant runtime and tool paths rather than relying only on src/index.ts.

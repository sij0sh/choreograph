# Symptom

Validation fails with "checkpoint.summary: must have required properties summary" when workflow_transition receives a checkpoint containing data but no summary.

# Cause

The checkpoint schema requires a summary property alongside the checkpoint data.

# Fix

Include a string checkpoint.summary in every workflow_transition checkpoint payload; retain structured details under checkpoint.data.

# Symptom

After reload, a workflow reports standard tools such as edit and write as unknown because the workflow tool declarations were compared against a narrowed tool set.

# Cause

The reload baseline was obtained from getActiveTools(), which may contain only the tools left active by the previous workflow.

# Fix

Use Pi's getAllTools() for discovery and baseline capture, with getActiveTools() only as a fallback for older Pi versions. Add regression coverage for reloading after a workflow has narrowed the active tools.

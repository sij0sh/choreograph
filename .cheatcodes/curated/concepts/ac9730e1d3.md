# Symptom

Per-iteration checkpoint keys collide, checkpointOrder collapses, and invalidation becomes ambiguous.

# Cause

The direct-loops-on-block-frame approach retains path-derived keys that are not unique for each iteration.

# Fix

Establish a runner-neutral execution model with invocation and scope identity, a scheduler, an event journal, and an artifact store before implementing loops or scripts.

# Answer

Render a Tools section in every workflow prompt using the active tool set, and pass that set from the coordinator into prompt rendering.

# Why

Silent tool narrowing caused agents to guess paths and attempt discovery with unavailable tools. Explicit grants make the procedure match the actual runtime capabilities.

# Symptom

Validation fails with “checkpoint.summary: must have required properties summary” and “checkpoint: must not have additional properties” when the checkpoint contains a data property instead of the required summary structure.

# Cause

The workflow_transition checkpoint schema requires a summary property and disallows additional properties such as data.

# Fix

Provide the checkpoint content using the schema-required summary property and remove unsupported additional properties from checkpoint.

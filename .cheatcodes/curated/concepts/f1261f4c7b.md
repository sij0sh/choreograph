# Symptom

The persistence layer has no event log or journal, artifact references or retention, completed-run history, scheduler state, or loop and invocation scope.

# Cause

src/persistence/store.ts defines SnapshotStore with only append(snapshot), and latestSnapshot scans the session branch for custom entries of type 'choreograph'.

# Fix

Treat persisted state as whole snapshots only; do not assume that event history, artifact storage, completed-run metadata, scheduler state, or iteration scope can be recovered from SnapshotStore.

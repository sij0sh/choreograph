# Symptom

Tool call rejected with: Validation failed for tool "workflow_transition" - checkpoint: must not have additional properties.

# Cause

The checkpoint argument was passed non-schema properties (data, majorWins, opportunities), and the checkpoint schema disallows additional properties.

# Fix

Pass only the fields defined by the checkpoint schema; do not bundle free-form payloads (data, majorWins, opportunities) under checkpoint.
